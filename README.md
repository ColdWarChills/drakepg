# drakepg

A browser turn-based RPG inspired by classic Flash-era adventure RPGs. Original names, story and art only.

Built with [Phaser 4](https://phaser.io), TypeScript and Vite. Runs in any modern browser (WebGL), desktop or mobile landscape.

## Run it

```bash
npm install
npm run dev      # local dev server with hot reload
npm run build    # production build into dist/
npm run preview  # serve the dist/ build locally
```

## What's in the game

**Chapter 1: The Restless Thornwood**, **Chapter 2: Rising Waters** and **Chapter 3: The Frozen Roost**

- **Title**: New Game / Continue (save in browser localStorage, including where you're standing).
- **Create**: type a name (or Random) and pick a class: **Warrior**, **Mage** or **Rogue** (click or **1-3**). Each has its own stats, gear and skills. **Start at Ch 1 / Ch 2 / Ch 3** skips ahead for testing: the level, spent stat points, earlier quests, gear and potions you'd have by then (`CHAPTER_STARTS` in `src/game/cheats.ts`).
- **Rooms** (DragonFable-style screens): walk with **WASD / arrows** or **click to walk**. Walk off an edge to change room. Buttons: Character, Inventory, **Map** and **Menu** (save, sound, story text, fullscreen, quit). **Story text** is off by default: quest givers say in one line what to do; turn it on in the Menu for the full dialogue.
  - **Unlocks by chapter**: Chapter 1 is just fights, elements, the shop, rolled gear and quests. Finishing it opens **Elites, treasure chests and the spare weapon**; finishing Chapter 2 opens **Sigils and Mimics**. (Materials and Hulda's forge are switched off for now.) Each unlock (and each new skill: name, cost and what it does) is announced once in a **New!** popup; new skills show **NEW** in battle until you use them. Data in `src/data/features.ts`; the testing menu's "All unlocks" opens everything.
  - **Rooms remember**: monsters you beat stay gone when you leave and come back; one wanders back per 45 seconds you're away.
  - **Treasure chests** sometimes stand in monster rooms (30% when a room fills up). Walk into one for gold, maybe a potion and often gear. One in four is a **Mimic**: a Tough fight (weak to Fire) that pays out like a chest. Mimics give themselves away: they breathe, and their lid twitches when you come near; real chests sparkle.
  - **The Old Road** (prologue): a new hero starts at Odo's overturned cart with only a weapon and walks six rooms west to Brindlemoor. The pests there (Burrow Rats, Dew Slugs, Hedge Pixies) hit for 1 and die in about two hits; one kill in three drops starter gear, armor most often. The road is one way: its last room opens into Brindlemoor's east gate, with no way back. Chapter starts skip it.
  - **Map** (button or **M**): one area at a time as dots and lines. Rooms you've been to show their name and icons (town, boss, campfire); the rooms next to them show as **?**. Quest marks: **!** a quest to pick up, **?** one to turn in, a gold ring where an active quest's monster lives. Dashed red = blocked for now. Arrows lead to the other areas you know.
  - **Recall Scroll**: takes you back to the last town you walked into. One way (you walk back out), never in battle. New heroes start with 5; every town shop sells them for 20g. Read one from the Inventory or the Map.
  - **Quiet rooms**: some rooms have no monsters. The first time you walk in, a short scene plays (dark bars, the camera drifts toward what's ahead). Things to look at sparkle (walk up and press **E**), and a **campfire** restores HP and MP once per visit. Side rooms hang off the **bottom edge** (a down arrow) or a cave mouth; some keep a **chest** (`room.chest`, never a mimic) that is always there the first time the room fills in a session. Each boss has a quiet room with a campfire right before it.
  - **Brindlemoor** (town): talk with **E / Space** or click. Elder Maren gives the story quests (**!** = new, **?** = ready to turn in), Tamsin runs the Adventurers' Guild board, Tobin the shop, Hulda the forge, Ilsa the inn. Garrick keeps watch on the Thornwood Path.
  - **Chapter 1** runs east of Brindlemoor: **Thornwood Path** (side room: the Hunters' Camp), **Fallen Oak**, the quiet **Woodcutters' Clearing**, **Deep Thornwood** (side room: the **Bramble Hideout**, a bandit den), the quiet **Briar Wall** (campfire, the thorn wall) and **Thornheart Hollow**. Monsters roam and chase you when you get close. Touch one to fight it. Label color and mark = level vs yours (▲▲ much higher, ▲ higher, ▼ much lower).
  - **Tough monsters**: most monsters are easy and weak to several elements, but a few are tagged **Tough** (orange): they hit hard and resist a lot, with one or two big weaknesses shown under their name. Ash Imp (fire immune, weak to Ice/Water), Barkshell Beetle (steel barely scratches it, weak to Fire/Wind) and Stormscale Drakeling (weak to Water). Bring the counter.
  - **Elites**: now and then (8% per roaming monster, at most one per room) a monster spawns as an Elite: bigger, glowing gold, tagged **ELITE**, one level higher, with 1.5x HP, 1.1x damage and one affix in its name (**Hulking** +50% HP, **Frenzied** +25% damage, **Warded** +25 all resistances, **Venomous** attacks may poison, **Ironhide** +50% defense; the battle panel spells it out). They give 3x XP and gold, always drop a piece of the area's gear, and roll Sigils far more often than normal monsters. An Elite still counts as its base monster for quests.
  - **Lucky Impling** (from the very start): now and then (1.5% per roaming monster, at most one per room) a small golden imp with a mint **LUCKY** tag and gold twinkles shows up. It runs from you instead of chasing, so corner it. In battle it is hard to hit and **runs away on its 3rd turn** (the panel counts down; a stun holds it in place for a turn). Catch it for about 5x the area's gold and a **1 in 10 shot at a Sigil** piece of the area's gear (Dawn 80%, Dusk 17%, Eclipse 3%), even before Sigils unlock. Sized to the area it appears in (`BALANCE.lucky`, `src/game/Lucky.ts`). **Testing:** `LUCKY_ON_NEW_GAME` in `src/game/cheats.ts` makes every new character meet one in the first monster room (off on the live build); the testing menu's "Lucky everywhere" spawns them on demand.
  - **Thornheart Hollow**: sealed by thorns until the Elder sends you there. Home of the chapter boss, who stays for **rematches** after its quest (half XP and gold, full loot; bosses drop Sigils far more often).
  - **Chapter 2** (level 6-10) runs west of Brindlemoor once the Elder asks: **Fen Road** (Mire Toads, Spark Wisps), the outpost **Reedwatch** (Captain Hale's quests, Wren's tier-2 shop with Greater potions, Sister Ottilie the healer), the rainy **Sunken Causeway** (Bog Lurkers, Sunken Revenants, Stormscale Drakelings; side room: the **Eel Pools**, Tough eels guarding a chest), **Whispering Reeds**, the quiet **Stilt Village**, **Bog Hollow** (mini-boss: the Bogmother), the **Stormlit Flats**, the quiet **Shrine Steps** and the **Drowned Shrine** (the Stormcoil). The Tough **Volt Eel** *absorbs* Energy: lightning heals it, so leave the Energy blade sheathed (Earth grounds it). Water monsters drop Water weapons and Energy monsters Energy ones; each is the other's weakness. Lose past Reedwatch and you wake at its healer.
  - **The Stormcoil changes form** at half HP: Energy becomes Water, its resistances flip, and the battle panel and log say so. Bring a neutral weapon, or one of each.
  - **Chapter 3** (level 10-14) goes north through Brindlemoor's mountain gate (a back exit: walk up into it) once the Elder asks: **Frostfang Pass** (Drift Wolves, Crag Rams), the village **Hearthold** (Ranger Sabine's quests, Gunnar's tier-3 shop with Superior potions, Hearthkeeper Moll's inn), **Windscour Ridge** (Gust Sprites, Rime Acolytes, the Tough **Glacier Golem**) with a cave mouth to the **Steamvent Caves** (Ember Salamanders, the Tough **Vent Wyrmling**, a chest; past them the quiet **Hot Springs**), **The High Trail**, the quiet **Ranger's Lookout**, **Snowmaw's Den**, **Whiteout Ledge** (the Frostbinder's acolytes), the quiet **Roost Stair** and **The Frozen Roost**. Ice monsters drop Ice Essence for Ice weapons (good in the caves), cave monsters drop Fire Essence for Fire weapons (good on the mountain); Hulda crafts both. The Ember Salamander *absorbs* Fire, so swap blades at the cave mouth.
  - **Old Snowmaw** wears a **Frost Shell** (pips on the battle panel): 60% less damage until 3 Fire hits break it, and it grows back once at half HP. **The Frostbinder** turns from Ice into a Wind blizzard at half HP: bring Fire, then Earth.
- **Quests**: the story, one short chain per chapter (tracker on the left): a quest that opens the way, then the bosses. The boss quests also need a **Guild rank** (Thornheart E, Bogmother D, Old Snowmaw C); until then the giver sends you to the Guild and the tracker says "Next: reach Guild Rank E". The last quest ends the chapter.
- **Adventurers' Guild** (`src/game/Guild.ts`, `src/ui/guild.ts`, numbers in `BALANCE.guild`): a Guild Clerk in every town (Tamsin, Ivo, Edda) shares one notice board. Ranks **F, E, D, C, B, A, S**; new heroes are F.
  - **Hunts**: *Hunt 5 Mire Toads* (3 of a Tough monster), *Gather 4 Bog Lilies* (any monster of that area drops one 50% of the time while the hunt is on; the battle panel's loot line shows it), and, after Chapter 1, an *Elite bounty* (one Elite of a monster). A hunt's rank comes from its monster's level (Tough and Elite one rank higher). The board only posts hunts where you can go (rooms reachable from a town you know, up to one room past where you've been), up to **2 ranks above yours**; lower ones only fill empty space. Hold up to 3; drop one any time.
  - **Turn in** at any clerk: XP and gold (the kills it takes, about doubled), and **rank points**: 1 at your rank, +1 per rank above, none below. 3/4/3/6/8/10 points promote you; promotions give gold and the old errand-quest gear (E: Leather Armor, D: Scale Mail / Reedweave Robe, C: Frostpelt Vest / Galeweave Robe). New notices go up after every turn-in.
  - Shown everywhere: the tracker, the result screen ("Hunt (D): Mire Toads 3/5"), a gold ring on the map where a hunt's monsters live, **?** over a clerk (and on the map) when one is done.
- **Battle**: turn-based. Attack / Skills / Items / **Defend** (-60% damage, regain MP) / Flee / **Swap** (mouse or keys **1-6**).
  - **Spare weapon** (after Chapter 1): a second weapon in the **Spare** slot next to the weapon (Inventory: drag a weapon onto it, or **As spare** on its card). **Swap** puts it in your hand mid-fight and **costs your turn**; the button shows its element and how it would land ("Water · Weak!"), and the hero panel shows the weapon in hand the same way. Its lines only count while it's in hand. Made for the two-form bosses (Stormcoil, Frostbinder): bring a weapon for each form.
  - **Intents**: the enemy panel always shows its **next move** and rough damage ("Next: Root Crush ~31 dmg · Defend or heal!"). Big attacks wind up a turn ahead: defend or heal.
  - **Signature moves**: most monsters have one, spelled out in a purple line on the panel: an **opener** (Thornback Boar's Thorn Charge), a move **every Nth turn** (Barkshell Beetle shells up every 3rd move), or a move **once when hurt** (Mire Toad heals 25% at 40% HP). Every boss winds up its big hit on a beat (every 3rd move: Defend on it), and each also tests one thing: the Thornheart Defend timing, the Bogmother burst (she heals every 4th move), the Stormcoil switching elements, Old Snowmaw bringing Fire, the Frostbinder lasting the distance (Blizzard on the even moves in her Wind form).
  - **Enrage**: from turn 15 (bosses 30) the enemy deals +20% damage per turn; the panel counts down the last 3 turns. Long fights without the counter end instead of dragging on.
  - **Absorb**: a resistance over 100 heals the monster instead ("Absorbs: Energy" on the panel, **Absorbed** on the hit).
  - **Heroic bosses**: after a boss's quest, its rematch prompt offers **Heroic**: +3 levels, +25% damage and a new move, for full XP and gold and two gear rolls.
  - **Elements**: Fire, Water, Ice, Wind, Earth, Energy, Light, Dark. Weapons, spells and monster attacks carry one (or none: neutral). Every monster's weaknesses and resistances are shown under its name; hits show **WEAK!** / **Resisted**. Rule of thumb: a creature resists its own element and is weak to the opposite (Fire/Ice, Water/Energy, Earth/Wind, Light/Dark).
  - **Attack types**: Melee (STR), Pierce (DEX), Magic (INT). Each has its own defense on armor and monsters.
  - **Skills** cost MP and most have a **cooldown** (turns until reuse, shown on the button). Hover a skill for its description. You **carry 5 skills** into battle: click a learned skill in the Character panel to carry it (◆) or put it away (◇). New skills fill a free slot.
  - **Mage**: Staff Bolt (no cooldown) hits in the **staff's element**; the other spells carry their own. Pick the staff for the area.
  - **Warrior Rage**: Warriors gain 3 MP whenever an enemy hit lands on them ("Rage +3 MP"), so they can keep using skills in long fights.
  - **Statuses**: burn, poison, bleed, stun, weaken, expose, buffs and more, shown as chips under each status panel with turns left.
  - **Weapon specials**: some weapons have a chance to trigger an extra effect when an Attack lands (shown in the item line).
- **Leveling**: each level gives **stat points** (spend with **+** in the Character panel) and unlocks class skills at set levels (12 per class, up to level 20).
- **Result**: XP and gold count-up, loot, quest progress, level-up. Loot pops in as cards, best last: plain drops just pop, Superior and Masterwork charge up first, Sigils get a long charge-up in their color before the fanfare (`BALANCE.dropReveal`). Losing wakes you at the inn with no penalty.
- **Equipment**: 8 slots from the start: **Weapon**, **Helm**, **Body**, **Gloves**, **Boots**, **Necklace** and two **Rings**. Armor of a tier is split by slot (body about 70% of the tier's defense, helm 20%, gloves and boots 15% each), so a full shop kit is a bit stronger than the body piece alone, and numbers stay small. Heavy pieces (leather, scale, ridgeplate) guard against melee and pierce, light ones (hoods, wraps, slippers) against magic. Each shop sells its tier's helm/gloves/boots; rings and necklaces only drop (the area's uncommon tier) and give stats, crit, resists or HP/MP. Only the body armor changes the hero's outfit.
- **Sets**: one per chapter area, 4 pieces each (helm, gloves, boots and a ring or necklace): **Thornwarden** (Thornwood), **Stormwatch** (the Fen), **Frostward** (Frostfang). Wearing 2 or 4 different pieces turns on bonuses (e.g. Thornwarden: 2 = +8% Max HP, 4 = +8% damage and Earth +15). The item card shows the set, worn pieces ticked and active bonuses lit; the inventory and Character panel list active set bonuses; equipping a piece shows which bonuses it switches on or off. Pieces drop from the area's **Elites (25%) and bosses (40%)** on top of their normal loot (shown as "Set 25%" on the battle loot line). Data in `src/data/sets.ts`, rules in `src/game/Sets.ts`.
- **Rolled gear**: every weapon and armor piece rolls a quality per line (Damage, Crit, Special chance / Defense, Max HP), 0-100%; rings and necklaces roll one line, **Power**, which scales everything they give (up to +50%). An armor piece's Max HP line counts by slot (body 70%, helm 30%, gloves and boots 20%). Shop gear is always **Standard (0%)**; monster drops and quest rewards roll, and high rolls are rare. A 100% Damage or Defense line adds +50%, so a perfect roll is about as strong as the next tier's 0% item (each weapon tier is about x1.5 the one before; items in the same tier are sidegrades). The average is the item's **grade**: Standard (grey), Fair (white), Fine (green, 40%+), Superior (blue, 70%+), Masterwork (gold, 90%+). Superior and Masterwork drops sparkle on the result screen.
- **Mods** (blue lines): extra lines like +STR, +Crit chance, +Max HP/MP or +resist to one element, each with its own 0-100% quality. For now only Sigil gear has room for them.
- **Gear drops**: one roll per kill, rarest first. A normal monster rolls **Rare** (the area's boss weapons) at 1%; only if that misses, **Uncommon** (the area's elemental gear) at 5%; then **Common** (plain gear of the area's tier) at 6%. Then an item is picked from that tier. Elites and bosses always drop something (Elite: Rare 5%, Uncommon 40%; boss: Rare 35%, Uncommon 50%). Adding items to a tier never changes how often the tier drops. Potions and materials roll separately.
  - **In battle** the enemy panel shows this fight's odds ("Gear  Rare 1%  Uncommon 5%  Common 6%"); hover or tap it for the items in each tier.
  - **Bad-luck protection**: each area counts your kills since its last Rare. After 80 dry kills, every kill adds +0.1% Rare (up to +20%), shown as "(luck)". A Rare resets the count. Half of players still wait about 70 kills, but the unluckiest 1% now get one by about 160 instead of 480.
- **Tiers and modifier slots**: every weapon, armor piece, ring and necklace has a **tier** (shown on its card: Tier 1 = Chapter 1 gear, Tier 2 = Chapter 2, Tier 3 = Chapter 3, Tier 4 = the Frostbinder's). The tier caps its modifier lines (quality lines plus blue mods): **T1: 1** (Damage / Defense only), **T2 and up: 2** for now (`BALANCE.modifierSlots`; the plan for later is T3-T5: 4, T6+: 6). Lines fill in order Damage, Crit, Special (armor: Defense, Max HP; jewelry has just Power); slots left over can hold mods, so with the current cap there are no mods or Special-chance lines. A Sigil still raises the base, but brings no mods.
- **Sigils**: rare versions of any dropped weapon or armor, shown with a **✦ Sigil of ...** line under the name. They are animated: the icon glows, swells and twinkles (Dusk and Eclipse also shed motes), and the weapon in hand glows and sheds motes and twinkles along the blade in its tier color, faster for rarer tiers. A Sigil weapon without art yet sparkles around the hero's weapon hand.

  | Tier | Base damage/defense | Extra lines | Normal monster | Elite | Boss |
  | --- | --- | --- | --- | --- | --- |
  | Sigil of Dawn (orange) | +20% | +1 | 2% | 8% | 20% |
  | Sigil of Dusk (violet) | +35% | +2 | 0.5% | 2% | 7% |
  | Sigil of Eclipse (crimson) | +60% | +3 | 0.05% | 0.3% | 1.5% |

  The chance is per gear drop. The Sigil raises the base first, then the white rolls apply on top. Its extra lines go above the tier's cap: first any quality line the cap left out (Crit, Special), then mods. Sigil drops arrive locked, sort first, sell for 3x/6x/12x, and get a fanfare on the result screen. Quest rewards and shop gear never have Sigils.
- **Inventory** (button or **I**): the hero with the 8 equipment slots around it (armor left, weapon and jewelry right; the spare weapon beside the weapon once it unlocks), a 30-slot grid with tabs (All / Weapons / Armor / Jewelry / Items: potions and stones / Materials when you carry any) and sorting. Drop a ring on the ring slot you want; double-click puts it in an empty one. Materials sit in their own pouch and take no bag slots. Hover or tap an item for its card: rolls with quality bars, and a comparison with what you wear. Equip by double-click, the Equip button, or dragging onto the hero; drag worn gear back to the grid to take it off. **Lock** keeps an item from being sold. Loot that doesn't fit a full bag is left behind (quest rewards always fit). Loot that doesn't fit a full bag is left behind (quest rewards always fit).
- **Shop**: Buy (Standard gear and potions) and Sell (better grades sell for more; **Sell junk** sells unlocked Standard/Fair gear, never Sigils or reinforced gear).
- **Rework** (every shop's third tab): pay gold to roll a weapon's or armor's Damage, Crit, Defense or Max HP line again, then keep the new value or the old one; high rolls are rare. It costs 30 g x the gear's tier, and 50% more with every rework of the same piece. The way to get stronger: find or buy gear, then rework its lines up.
- **Crafting and materials are off for now** (the forge, recipes and material drops stay in the code for later). Chapter 3's Ice and Fire weapons are sold in Hearthold.
- **Phones and tablets** (landscape): tap the ground to walk and tap people to talk; **hold** a battle button (or a skill in the Character panel) to read its description without using it. Names in rooms grow on small screens, a **Fullscreen** button appears where the browser supports it (not on iPhone Safari), and holding the device upright shows a "turn sideways" screen.
- **Character panel** (button or **C**): stats, stat points, skills, what you have equipped. **M** opens the map (sound is in the Menu). **Esc** closes windows.
- **Gear you can see**: the weapon is drawn in the hero's hands, and body armor changes the hero's outfit once its art exists (`char_<class>_<armor id>`; see the Art section).
- **Cheats** (for testing; hidden): in any room press **`** (backtick), or tap the room name 5 times on a touch screen.
  - **Hero**: levels (+1, +5, to 5/10/15/20), gold, full heal, refund stat points, clear the bag, toggles for god mode, one-hit kills, Elites everywhere and a Lucky Impling in every monster room, and **Rates x1 / x2 / x5 / x10**: XP and gold earned (kills, chests, quests) and every drop chance (gear tiers, Sigils, set pieces, potions, chests), each chance capped at 100%. At x10 a normal monster drops gear about 4 kills in 5 and a Rare 1 in 10; the battle panel's odds show the boosted numbers. Toggles and rates last until the page reloads.
  - **Give item**: any item with a chosen quality, Sigil and number of mods (potions in fives).
  - **Wardrobe**: try on every weapon and armor and see it on the hero right away (faded = no art yet).
  - **World**: teleport to any room, respawn monsters, mark quests done (with everything before them, and the Guild rank they need), finish active quests and hunts, reset quests, Guild rank +1, reset the Guild, and reset the character.
  - Everything except the toggles changes your real save.
- **Sound**: all effects are synthesized in code (WebAudio), no audio files.

### Art

1. Generate images with the prompts in [`art/PROMPTS.md`](art/PROMPTS.md) and put them in `art/raw/`, named by key (e.g. `mon_mossling.png`). Everything still missing, with ready prompts in priority order: [`art/QUEUE.md`](art/QUEUE.md).
   With ComfyUI + Qwen-Image 2.1 running locally, `python3 scripts/qwen_batch.py <key>` generates queue images straight into `art/raw/` (transparent PNGs, the game's art as style references; `--variants 4` for options in `art/review/`).
2. Run `python3 scripts/prepare_art.py` (needs Pillow + numpy). It removes flat backgrounds from sprites (or uses a PNG's own transparency), trims, resizes, and writes WebP files to `src/assets/art/`. Keys whose processed file was touched up by hand (`HAND_EDITED` in the script) are skipped unless `--force`.
   Files are saved at 2x as `<key>@2x.webp` (backgrounds 2560x1440, sprites 960px tall) so they're sharp on a 1440p screen; the game draws them at the 1x size (1280x720, 480px), so old 1x files (`<key>.webp`) keep working next to them. A source too small for 2x is saved at 1x; `--1x` forces it.
3. Every file in `src/assets/art/` is loaded at boot by its file name. Point data at it with `look.art`, `zone.background` or `room.background`. Item icons need no data: `icon_<item id>` replaces the drawn icon in the inventory, shop and forge (fit in 256x256 at 1x, 512x512 at 2x).

Armor outfits: wearing an armor, a hero is drawn from `char_<class>_<armor id>` (empty-handed like the bare art) when it exists, else the default look. Its fists default to the class's `bare.hands`; `prepare_art.py` crops outfits exactly like the bare art, so as long as the outfit is an edit of the bare image at the same size, they stay put (otherwise set `hands` per class on the armor in `items.ts`). Prompts are at the end of `art/PROMPTS.md` and `art/QUEUE.md`.

Weapons in hand: heroes have weaponless art (`char_<class>_bare`, made by editing the hero image to empty fists). `look.bare.hands` in `classes.ts` holds each fist's pixel position in that processed image at 1x (480px tall; halve what you measure on a `@2x` file) and the weapon's idle angle; **re-measure them if the bare art is regenerated**. Weapon images are `wpn_<id>`, drawn upright with the handle at the bottom (the script makes them 640px tall at 2x, 320 at 1x); a weapon's `art`, `grip` (0 = top, 1 = bottom of the image: where the fist holds it) and `size` (length relative to the hero) are set in `items.ts`. Weapons are drawn behind the body so the fist covers the grip. A weapon without art falls back to the hero's original picture.

### Adding content

- **Room**: add to `ROOMS` in `src/data/world.ts` with its walkable strip (`walk`), `exits` (left/right to another room, `side: 'back'` with an `x` for a door, gate or cave mouth in the art that you walk up into, or `side: 'down'` with an `x` for a path off the bottom edge to a side room; you arrive at the matching exit of the other room), a `map` spot (`area` from `src/data/map.ts`, grid `x`/`y`; one room per spot), `npcs`, and optionally a `zoneId` + `monsterCount` for roaming monsters, `ambient` particles (dust, leaves, fireflies, rain, mist) and `wakeAt` (where you wake after losing there; default the Brindlemoor inn). Optional: `town` (a Recall Scroll lands you at this spot), `chest` (a side room's sure chest), `campfire`, `inspect` (notes, signs, marks, bones with lines to read) and `firstVisit` (lines shown once on entry, `panTo` an x the camera drifts toward). Link it from a neighbor's `exits`. Without art, `backdrop.kind` draws a town, forest, marsh, outpost, snow, village or cave; a back exit's `frame` draws a gate or cave mouth until the art shows one.
- **Monster**: add to `src/data/monsters.ts` (with an `element`, `resists` in percent (over 100 absorbs), `defense` per attack type, and `immune` statuses if any), then add it to a zone's `encounters` in `src/data/world.ts`. Give it a `loot` table for gear; `drops` is for potions and materials only. An attack can `applies` statuses; `power: 0` makes it a pure buff, `heal` heals a share of its max HP. Signature moves are never picked at random: `opener` (its first move), `every: 3` (every 3rd move), `hpBelow: 0.4` (once, when hurt). Describe them in `trait` (shown on the battle panel). Normal monster damage is scaled by `BALANCE.mobDamage`, bosses by `BALANCE.bossDamage`.
- **Loot table**: `src/data/loot.ts`. Each table splits an area's gear into `rare` / `uncommon` / `common`, with an optional `weight` per item. Tier odds per kill are in `BALANCE.loot` (`mob`, `elite`, `boss`), bad-luck protection in `pityAfter` / `pityStep` / `pityMax`. `npm run sim` prints the exact odds per table and source.
- **Set**: add to `SETS` in `src/data/sets.ts` (pieces and bonuses at N pieces: stats, `hpPct`, `crit`, `resists`, `damagePct`, `defensePct`), give each piece `set: '<id>'`, put `set` on the area's loot table for Elite/boss drops (`BALANCE.setDrop`) and add recipes.
- **Material / recipe**: add to `MATERIALS` / `RECIPES` in `src/data/crafting.ts` (Hulda lists every recipe); forge numbers are in `BALANCE.forge`, rules in `src/game/Forge.ts`.
- **Item**: add to `src/data/items.ts` (weapons, body armor, potions) or `src/data/equipment.ts` (helms, gloves, boots, rings, necklaces, set pieces), then to a shop's `stock`, a loot table's tier (gear) or a monster's `drops` (potions, materials). Weapons take a `damageType`, an optional `element` and an optional `proc` (special); armor takes a `slot` (body by default), `defense` per type and `resists`; accessories (`type: 'accessory'`, `slot: 'ring' | 'necklace'`) take `stats`, `hp`, `mp`, `crit` and `resists`, all scaled by Power. Items without art get a drawn icon tinted with `iconColor`. Roll ranges, drop curve, bag size and sell prices are in `BALANCE` (`gearRolls`, `rollCurve`, `bagSlots`, `sellRate`, `sellGradeBonus`), and so are Sigils and mods (`sigils`, `sigilChance`, `modChance`, `modRanges`); roll rules and the mod pools live in `src/game/Items.ts`. Drops from a `boss: true` monster use the boss Sigil chances.
- **Skill**: add to `src/data/skills.ts`, then to a class's `skills` in `src/data/classes.ts` with the level that unlocks it. Set `cooldown`, and `element`/`damageType` if it shouldn't use the weapon's. `applies` adds statuses (`self: true` for buffs). `fx: 'heavy'` gives a leap (or a big spell).
- **Status**: add to `src/data/statuses.ts` (damage over time, regen, stun, damage/defense/resist/hit/crit modifiers).
- **Tough monster**: `tough: true` on a monster adds the Tough tag in rooms and battle. Rule: trash is neutral with several small weaknesses; a tough one resists a lot and has one or two big weaknesses the player can get a counter for in that chapter.
- **Elite affix**: add to `src/data/elites.ts` (`hp`, `damage`, `defense` multipliers, `resists`, `applies` added to every attack) with a `description` the battle panel shows. Spawn chance, stat and reward multipliers are in `BALANCE.elite`; Elite Sigil odds in `BALANCE.sigilChance.elite`. Any monster can become an Elite; its guaranteed drop comes from the gear its zone's monsters drop.
- **Class**: add to `src/data/classes.ts` (stats, per-level `growth`, starting gear, skills, look, optional `mpOnHit` for Rage) and to `ClassId` in `src/data/types.ts`.
- **Quest**: add to `src/data/quests.ts`. `giver` is an NPC id, `requires` chains it after another quest, the objective kills a `monsterId` or any Elite (`elite: true`, which also makes Elites spawn more often while it's active), or collects items (`kind: 'collect'`, `itemId`, `count`: counts what's in the bag, taken on turn-in; potions and materials only), `classItems` gives a different reward per class, `endsChapter` shows the chapter-complete screen. A room exit with `requiresQuest` stays blocked (by thorns, or its `blocker`: barricade, reeds or snowdrift) until that quest is accepted; a room `boss` appears once its quest is accepted and stays for rematches (`BALANCE.bossRepeatRewards` XP and gold).
- **Boss**: a monster with `boss: true` (can't flee). `heroic: { text, attacks }` adds the Heroic rematch's new moves (`BALANCE.heroic`, `src/game/Heroic.ts`). An attack with `windup` text is telegraphed one turn before it hits. A `phase` changes its element, resistances and attacks once its HP drops below a share (the Stormcoil at 50%). A `shell` (name, element, hits, reduction, optional `reformAt`) soaks up damage until enough hits of that element break it (Old Snowmaw). The room's `boss.intro` is the line shown before the fight. **Boss grit**: every loss to a boss adds +5% damage against it (max +25%, `BALANCE.grit`), shown on the battle panel and the defeat screen; beating it resets.

Broken references (e.g. a drop pointing at a missing item) throw at startup in `validateData()`.

### Balance check

`npm run sim` plays thousands of battles headless (same rules as the game) with a simple AI and prints win rate, HP left, turns and potions used per class and monster. Each cell also runs a random-button bot (`rnd`, drinks a potion when low): when it does as well as the smart AI, decisions don't matter in that fight. Run it after changing monsters, skills, items or `BALANCE`. `npm run sim -- 2000` for more battles per cell, `npm run sim -- 400 stormcoil` to print only the tables that mention a word.

`npm run pace` estimates pacing: a bot plays the road and each chapter's quests through the real rooms (shortest walk, fights what roams there, rooms refill like in the game) and prints rooms per chapter, fights, level at each boss and rough minutes. The seconds per action are guesses (`TIME` in `scripts/pace.ts`), so compare runs with each other; a timed run by hand is the real check. Run it after changing rooms, quests or monster XP.

### Saves

Older saves are migrated (pre-class saves become Warriors; pre-v4 gear becomes Standard; v5 added Sigils and mods, which old gear simply doesn't have; v6 added the smith's + and materials; v7 added the bad-luck counters; v8 added boss grit; v9 unlock popups; v10 the skill loadout; v11 the 8 equipment slots, and the old armor slot became Body; v12 visited rooms and the last town, and old characters get the 5 starting Recall Scrolls; v13 the spare weapon slot, empty). ## Playing on GitHub Pages

Every push to the default branch deploys to `https://coldwarchills.github.io/drakepg/`.

One-time setup: repo **Settings → Pages → Build and deployment → Source: GitHub Actions**. Until that's set, the workflow skips the Pages step. After enabling, re-run it from **Actions → Build & deploy → Run workflow** (or just push).

## Deploying to itch.io

GitHub Actions builds every push. To also upload to itch.io from the default branch:

1. On itch.io create a project, **Kind of project: HTML**. Set the embed size to 1280×720 (or tick "automatically start on page load" / fullscreen button as you like).
2. itch.io → Settings → API keys → generate a key.
3. GitHub repo → Settings → Secrets and variables → Actions:
   - **Secret** `BUTLER_API_KEY` = the key.
   - **Variable** `ITCH_GAME` = `yourname/your-game` (from the project URL `yourname.itch.io/your-game`).
4. Push. The workflow uploads `dist/` to the `html5` channel. On the first upload, open the itch.io edit page and tick "This file will be played in the browser" for that upload.

Manual alternative: run `npm run build`, zip the **contents** of `dist/` (so `index.html` is at the zip root) and upload the zip on itch.io.
