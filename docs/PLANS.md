Early on you can only take the lowest hunts, which fit what you can reach. Hunts are "kill X monsters" or "bring X items from one place" (any monster there can drop them). You can take hunts up to 2 ranks above your own. Hunts match the player's level and strength. S rank is late game; now and then a big S-rank mission.
- **Built with these defaults** (all easy to change, see `docs/IMPROVEMENTS_2026-10.md`):

## Skills, weapons and builds (discussed 2026-10-15)

Facts from the code at the time: Warrior and Rogue skills take the equipped weapon's element and damage type (daggers are pierce, so Rogue skills scale on DEX); only 11 skills, mostly the Mage's, have a fixed element. Stormcoil (Energy -> Water) and the Frostbinder (-> Wind) change element mid-fight. Gear has no "+element damage" line, only a resist per element. Stat points can't be refunded (only the cheat menu can). Monster weaknesses are -50 to -75, resists up to +75.

- **Built (2026-10-15):** mid-fight weapon swap (Spare slot, Swap costs the turn), see `docs/IMPROVEMENTS_2026-10.md`. Why: players won't own the best weapon of every element, so it keeps pushing upgrades; a weaker backup in the right element still beats a strong weapon in the wrong one.
- **Open:** the spare slot unlocks after Chapter 1 (with Elites and chests), so the Stormcoil is the first boss it matters for. Keep, or from the start?
- **Playtest:** is the Swap button clear? Does a swap feel worth a turn outside the two-form bosses?
- **Next big step (designer, 2026-10-26): build variety (skills from drops, element families, spellbook) goes first, then Chapter 4.** Spec it before building.
- **Decided (designer, 2026-10-26): skills come from a mix.** Levels keep each class's core (~6 skills); the rest come from drops, town shops and bosses, even some early ones, not all of them strong. The strongest come only from sure sources (a boss's first kill, Heroic rematches, a Lucky Impling, a side room's sure chest, class quests), never random trash drops (bad-luck protection rarely kicks in).
- **Decided (designer, 2026-10-26): element skill families with a fixed element plus a match bonus.** The same skill in different elements, so a player can build e.g. a fire Rogue. The shape is per class (e.g. Warrior strike, Rogue knives, Mage bolt: Light Bolt and Staff Bolt already exist), the 8 elements are shared. A family skill always has its own element (Fire Knives = Fire) and gets a bonus, shown on the skill, when the weapon has the same element, so the weapon's element and the swap still matter. Damage type follows the class's weapon, so a Rogue's element skills scale on DEX, a Mage's on INT.
- **Decided (designer, 2026-10-26): a spellbook with hints.** Every skill listed, unknown ones as dark pages with a hint where to find them ("Dropped by a Mirewater Elite"), tabs per element (HoMM3-like). Replaces the skill list in the Character panel.
- **Proposed (designer, 2026-10-26): class quests.** Short quests that unlock more skills; not too long, a soft gear check.
- **Proposed (designer, 2026-10-26): advanced classes.** At level 20 each class picks one of 2 advanced classes with a clear identity through a weapon, e.g. Warrior -> Technician (rapiers or one-handed swords) or Brute (two-handed swords). Any class can still equip any weapon (true today: no class locks, stats and damage type do it); the advanced class's skills need its weapon kind. More picks at level 40 ("additional 2").
